## 📖 About

**GoShare** is a ride-sharing marketplace that helps travelers with available seats connect with passengers heading to the same destination.

Instead of driving with empty seats or struggling to find transportation, GoShare makes intercity travel more affordable, efficient, and eco-friendly.

> **Example:** Ahmed is traveling from **Annaba → Algiers** with 3 empty seats. Sarah needs to travel on the same day. GoShare connects them instantly.
